# Emberforge — Generated Art Asset Prompts

The game ships with crisp procedural 16-bit pixel-art placeholders for every slot below so it is immediately playable offline.
To override any placeholder with custom generated art, place a PNG with the exact `<id>.png` filename in:

`public/assets/generated/<id>.png`

Rebuild (`npm run build`) and the asset loader will automatically use your PNG instead of the procedural art.

All prompts end with the required style suffix:
`16-bit SNES pixel art, limited palette, crisp pixels, no anti-aliasing, flat magenta background`
